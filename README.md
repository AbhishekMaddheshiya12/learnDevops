# DevOps Task Manager

A full-stack Task Manager application built as part of hands-on DevOps training.

## Tech Stack

### Frontend
- React
- Vite

### Backend
- Node.js
- Express.js

## Features

- Create tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Backend health endpoint

## Local Development

### Start the backend

```bash
cd backend
npm install
npm run dev
